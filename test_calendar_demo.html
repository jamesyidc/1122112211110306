✨ 核心功能

  • 点击日期即可打开日历弹窗，快速跳转到任意历史日期
  • 可用日期蓝色高亮显示，无数据日期自动置灰不可选
  • 今日日期带青色特殊标记，一眼识别当前时间
  • 年月下拉选择器 + 左右箭头，快速切换查看月份
  • "今天"按钮一键回到最新数据
  • 支持点击遮罩层或取消按钮关闭弹窗

🚀 使用方法

  1. 打开页面: 访问 SAR偏向趋势图
  2. 点击日期: 在页面顶部中间区域点击当前显示的日期（例如 "2026/03/06"）
  3. 选择日期: 在弹出的日历中点击任意蓝色高亮的日期
  4. 查看数据: 页面自动加载所选日期的SAR偏向趋势数据
